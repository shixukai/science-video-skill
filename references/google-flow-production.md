# Google Flow cloud production

> **Route isolation:** When `design.production_route=google_flow`, use this handbook with [voice-reference.md](voice-reference.md), [viral-appeal-and-packaging.md](viral-appeal-and-packaging.md), [realistic-direction.md](realistic-direction.md), and only needed cover/QA/release sections. **Do not load `tool-routing.md`, `ai-generated-video.md`, `engineering-blender.md`, `blender-execution.md`, `material-rendering.md`, or `spatial-typography.md`, and do not activate local realistic or 3D rendering toolchains.**

## Select the route and budget bilingual chains at G1

Set `design.production_route=google_flow` for Google Flow cloud commissions. Two sanctioned cloud execution modes are supported on this route, sharing identical HD, `24/1 fps` CFR, bilingual, ledger, and audit rules:
- **Mode A — Headless Gemini API CLI (`gemini_api_cli`, via [`scripts/gemini_api_cli.py`](../scripts/gemini_api_cli.py) wrapping [`gemini-api`](https://github.com/google-gemini/gemini-api-cli)):** Scriptable cloud execution mode whenever `gemini-api` is installed and authenticated with a Gemini API key or Cloud OAuth token (`python -X utf8 scripts/gemini_api_cli.py preflight --check-auth` → `status: "ready"`), eliminating browser viewport fragility and web-UI anti-bot friction. Supports headless `1080p`/`4k` video generation (`gemini-omni-1.2-flash`), `-i/--input` frame/reference conditioning, `--previous-interaction-id` continuations, `--async`/`resume` durability, `2K` text-free keyframes and cover art (`gemini-nano-banana-2.1`), optional ducked BGM stems (`lyria-3.5`), and optional cloud TTS (`gemini-3.8-flash-tts`). Note: `gemini-api` bills against a Gemini API key / Cloud project and cannot draw consumer Flow web AI credits. See [Gemini API CLI headless cloud execution](#gemini-api-cli-headless-cloud-execution).
- **Mode B — Google Flow Web UI (`google_flow_web`, [flow.google.com](https://flow.google.com/)):** Default when consuming Google AI Pro/Ultra Flow web AI credits, whenever `Veo 3.1 - Fast`/`Quality` models are commissioned, or as automatic zero-friction fallback whenever `scripts/gemini_api_cli.py preflight --check-auth` reports `unavailable` or `unauthenticated` (no API key configured). Episodes may combine `gemini_api_cli` and `google_flow_web` clips on the same `google_flow` route so long as every clip satisfies `>= 1080` short edge, `24/1 fps` CFR cadence, full ledger provenance, and `google_flow_audit.py`.
- **Visuals & physical foley:** Generate all delivered video imagery and physical foley (`>= 1080p`, `24/1 fps` CFR) via `gemini-api-cli` or Google Flow Web UI. OS TTS, local 3D renderers, local video-assembly pipelines, screen capture, and stock footage/music cannot supply delivered media on this route.
- **Narration & muxing:** Synthesize continuous **Chinese (`zh`)** narration via local IndexTTS-2.5 `#5` voice clone ([synthesize_indextts2.py](../scripts/synthesize_indextts2.py)) + `#5` speech polish ([prepare_voice_master.py --polish](../scripts/prepare_voice_master.py), `mandarin-clone-polish-v1`, zero echo) — or `edge-tts` (`zh-CN-YunxiNeural`, `+4%`) / optional `gemini-api tts` (`gemini-3.8-flash-tts`) as cloud fallback — and paired **English (`en`)** narration via `edge-tts` (`en-US-AndrewMultilingualNeural`, `+4%`, [synthesize_edge_tts.py](../scripts/synthesize_edge_tts.py)) or optional `gemini-api tts` mastered linearly via `prepare_voice_master.py`; composite (`ffmpeg`) with `1080p` cloud visuals, ducked physical foley/ambience, and synchronized captions.
- **Explanation-led runtime & visual acts:** Plan the full [causal chain](topic-contract.md#complete-chains-and-duration-for-engineering-and-manufacturing-topics) first with **no minimum or maximum runtime or word-count quota**. Group shots into sustained visual acts (`2–4` consecutive shots bridged via `-i/--input` tail-frame conditioning, `--previous-interaction-id`, Flow `Frames`/`Extend`, or a shared scene preamble — never ping-ponging exterior/studio on single shots, and never tacking caveats onto the end with `；`).
- **Paired bilingual budgeting (`24/1 fps` CFR):** Deliver sibling `episode.zh.json` and `episode.en.json` sharing shot order, picture clips, truth registers, and foley stems. Raw `1080p` clips typically run `~7.8–8.0 s` (`~188` frames at `24/1 fps`); after trimming `0.15–0.40 s` ramp head and holding `0.20–0.40 s` tail margin, each clip yields **`~6.8–7.4 s` usable core**. Budget every shot to `max(span_zh, span_en)` at G1: split longer beats into `SHxxA`/`SHxxB` or tail-frame conditioning continuations — **never** use `setpts` slow-mo, `tpad` tail freezes, loops, or `atempo` audio warping. Lock `design.output.fps=24` CFR on pure Flow/Omni timelines (never duplicate frames to `30 fps`).

## Gemini API CLI headless cloud execution

Use [`scripts/gemini_api_cli.py`](../scripts/gemini_api_cli.py) (wrapping `google-gemini/gemini-api-cli`, `source_id: "google-gemini-api-cli"`, Apache-2.0) for non-interactive, ledger-tracked cloud media generation on the `google_flow` route. Installing or reading this Skill grants no Gemini API spend authorization; follow explicit task authorization before issuing billable requests.

- **Preflight & credential hygiene:** Run `python -X utf8 scripts/gemini_api_cli.py preflight --check-auth` first (read-only binary, version, and masked `whoami` source check; add `--verify-live` only when testing live API connectivity). Credentials resolve in precedence order: `--api-key`/`--access-token` → `GEMINI_API_KEY`/`GEMINI_ACCESS_TOKEN` env var → OS keychain (`gemini-api configure`) → `~/.config/gemini-api/config.yaml` (check `whoami` so an exported `GEMINI_API_KEY` does not unexpectedly override a stored project key). **Never** invoke interactive commands (`configure --interactive`, `auth login`, `explore`) from agent shells, always pass `--no-interactive`, never print or commit keys/tokens/config files, and preview new `--body` payloads offline with `--dry-run` before billable execution. If unavailable or unauthenticated, fall back honestly to Google Flow Web UI (`google_flow_web`) or report the missing binary/credentials.
- **Mandatory `1080p` HD guard & Omni 1.2 Flash controls on `gemini-api video`:** Upstream `gemini-api video` **defaults to `720p`** if `--resolution` is omitted (and CLI versions `<= v0.4.5` default to `gemini-omni-1.1-flash`). Always generate formal clips through `scripts/gemini_api_cli.py video` (explicit `--model gemini-omni-1.2-flash --aspect-ratio 16:9 --resolution 1080p`, or `4k`; `--allow-proxy-720p` is strictly for internal screening proxies). `gemini-omni-1.2-flash` supports `3s–15s` clips (`10s` default; pass `--duration 8s` or `10s` via `--body` as budgeted; two-frame transitions and extensions cap at `3s–10s`, up to `30s` cumulative). Because Omni 1.2 Flash tries to auto-cut across multiple shots by default, explicitly state `"In a single continuous shot, no scene cuts. No dialogue."` when you want one unbroken physical beat. Keep server-side `store` enabled (setting `"store": false` conflicts with `background: true` and breaks `--previous-interaction-id`). Inspect available models with `scripts/gemini_api_cli.py models` (offline catalog) or `models --live`, and use `gemini-api video --help` (avoid dumping raw ~92 KB `--schema` directly into context).
- **Natural-language conditioning, continuity & >14 MB uploads:** Pass starting frames, first+last keyframes (`<= 10s`), or up to 6 reference images via repeatable `-i / --input <path-or-files/id>` and bind their roles in plain natural language by order (e.g., `"Use this image as the starting frame..."` or `"Use the first image as the starting frame and the second image as the final frame..."` — never use deprecated `<FIRST_FRAME>`/`<LAST_FRAME>` tags), or continue/edit a prior generation conversationally with `--previous-interaction-id <response_id>` (for targeted edits add `"Keep everything else the same."`). Because `gemini-api` keeps inline payloads under `20 MiB` base64 (`~14 MB` raw), `scripts/gemini_api_cli.py video` automatically uploads larger local conditioning files via `gemini-api files upload <path> --wait` (48 h retention) or you can pre-upload via `scripts/gemini_api_cli.py upload <file>`. Note regional restrictions: video-to-video uploads for editing/extension/reference are unavailable in EEA/Switzerland/UK and some US states.
- **Single-submission durability (`--ledger` & `--async`/`resume`):** Always pass `--shot-id <SHxx> --ledger <prompt-ledger.json> --receipt <new-receipt.json>`. The wrapper writes a `"pending"` ledger entry before invoking the API and persists `response_id`, output path, SHA-256, and `ffprobe` stream probes (`width`, `height`, `avg_fps`, `r_fps`, `duration_s`, `audio_sample_rate`) on completion. For long jobs or timeouts, use `--async` to capture the interaction ID immediately and recover cleanly via `python -X utf8 scripts/gemini_api_cli.py resume <interaction_id> --out <clip.mp4> --shot-id <SHxx> --ledger <prompt-ledger.json> --receipt <new-receipt.json>` — **never blindly resubmit** an unknown in-flight generation.
- **Keyframes, text-free covers & optional stems:**
  - Generate `16:9` conditioning keyframes or text-free realistic cover backgrounds (`3:4`, `4:3`, `1:1`, `16:9`) via `python -X utf8 scripts/gemini_api_cli.py image "<prompt>" --aspect-ratio <ratio> --image-size 2K --out <still.jpg> --receipt <new-receipt.json>` (`gemini-nano-banana-2.1` default; keep text-free and typeset separate `zh`/`en` covers strictly via `scripts/compose_cover.py --lang zh|en`).
  - Optional ducked BGM stems may use `scripts/gemini_api_cli.py music` (`lyria-3.5` default) on their own ducked stem within verified API terms.
  - Optional cloud TTS via `scripts/gemini_api_cli.py tts --script-file <script.txt> --language <zh-CN|en-US> --out <raw.wav> --receipt <gen.json>` (`gemini-3.8-flash-tts`, 24 kHz mono WAV; master to 48 kHz via `prepare_voice_master.py`) emits a `check_episode.py`-compatible generation record (`provider="Google"`, `backend="gemini-api-cli"`, `location="https://generativelanguage.googleapis.com/v1beta/interactions"`). Default narration still remains local IndexTTS-2.5 `#5` Mandarin clone + `edge-tts` English unless explicitly overridden.
  - Optional `gemini-api transcribe --input <audio> --format srt --out <captions.srt>` or bounded `gemini-api analyze` calls obey [minimal outbound media](../SKILL.md#local-review-links-and-bandwidth-conservation) and never replace independent G5 normal-speed audiovisual viewing and dual listening.
- **Post-generation inspection remains mandatory:** Every CLI-generated clip is recorded `review_status="generated_unreviewed"`. Verify `ffprobe` streams (`>= 1920×1080`, `24/1 fps` CFR or explicitly audited fps, clean `48 kHz` foley vs muted gibberish) and inspect contact sheets plus full-resolution `1920×1080` Frame 0 / hero stills and `4–8 s` tails before assembly.

## Start with active project controls, pacing and 1080p Upscaled staging

When executing in **Mode B (Google Flow Web UI, `flow.google.com`)**:
- **Desktop viewport lock (`>= 1440×900`):** Enforce `1440×900+` at the start of every browser step and after navigation (below `~840 px`, Flow switches to mobile layout and hides `Scenes`, `+ Add clip`, and `>> Extend`). Check active models/credits (`Veo 3.1 - Fast` 10 cr/8s, `Veo 3.1 - Quality` 100 cr/8s, `Omni 1.2 Flash` 24 cr/8s; `1080p Upscaled` = 0 cr on single clips). [Flow docs](https://support.google.com/flow/answer/16353333?hl=en&co=GENIE.Platform%3DDesktop), [Models](https://support.google.com/flow/answer/16352836?hl=en), [Credits](https://support.google.com/flow/answer/16526234?hl=en).
- **Disk-backed prompt ledger:** Save a versioned local ledger mapping every `shot_id` → exact prompt, backend (`gemini_api_cli` | `google_flow_web`), input mode (`Text`/`Frames`/`Ingredients`/`-i`/`--previous-interaction-id`), expected span, interaction ID or card index, and downloaded filename; re-read from disk after any compaction/resume.
- **Strict 1-by-1 serial submission & anti-bot stop (Web UI):** Submit and upscale one card serially at calm human pace (never parallel tabs/burst loops). On `"We noticed some unusual activity"`, CAPTCHA, sign-in, region, or credit block: **stop immediately**, save state, and report to the user (never bypass).
- **Asset reuse & `1080p` verification:** Reuse clean project cards/`Frames`/CLI clips under [minimal transfer](../SKILL.md#local-review-links-and-bandwidth-conservation). Download every selected Web UI single clip via **`1080p Upscaled`** (`720p Original` is screening-only), verify `dl.path() !== null && dl.failure() === null`, probe with `ffprobe` (`>= 1920×1080`, `24/1 fps`, valid video + `48 kHz` audio), and inspect BOTH contact sheets AND **full-resolution `1920×1080` Frame 0 / hero stills** before assembly.

## Prompting, conditioning, clean phantoms and native foley

Draft every prompt from its [shot card](realistic-direction.md#write-a-shot-card-before-the-prompt) (`truth_register`, `time_scale`, scene lighting preamble, camera package, concrete physical transition) and select candidates science-first:
1. **0–5 s hook sample & G3 first:** Produce `SH01` at `>= 1080p` first (`scripts/gemini_api_cli.py video --resolution 1080p` or Flow Web `1080p Upscaled`), trim `>= 0.15 s` (`>= 4` frames) of static ramp so motion starts at frame 0 ([two-second hook](viral-appeal-and-packaging.md#win-the-first-two-seconds)), inspect full-res `1920×1080` Frame 0, and pass `opening_hook.py` + cold 2 s test + G3 before generating remaining body shots.
2. **Frameless, text-free staging (`>= 90%` safe zone):** Keep props/instruments blank and unmarked; never prompt counters, labels, split screens, PiP insets, borders, or UI mockups (cloud video models garble glyphs).
3. **Zero body horror / clean biological cutaways:** Under [disturbing-imagery rules](visual-system.md#handle-potentially-disturbing-imagery), NEVER prompt or accept peeled/carved/translucent human skin, exposed wet subcutaneous vessels, or needle piercings on human hands/limbs (in video or covers). Open on clean intact exteriors and cut to standalone non-fleshy microscopic optics or clean non-photorealistic schematics; preserve soft-tissue compliance (never metal pistons/blades for soft organs) and check `4–8 s` tails for late morphs.
4. **Physical foley only inside Veo/Omni prompts:** Live verification shows Flow has no voiceover upload lane and `Veo 3.1 - Fast` rejects offscreen Mandarin speech prompts (`35%–57%` `Audio generation failed`), whereas literal physical `Audio:` foley prompts succeed cleanly. Prompt pure physical visuals + literal `Audio:` foley in `gemini-api video` and Flow Web, then mux continuous `#5` IndexTTS-2.5 Mandarin / `edge-tts` English narration in FFmpeg.
5. **`1080p` vs `720p` platform limits:** In-editor Flow `>> Extend` (`Omni 1.2 Flash`, `+4 s`) and `/scene/` `Download scene` currently export `1280×720` only, and bare `gemini-api video` defaults to `720p` unless `--resolution 1080p` (or `4k`) is passed (`720p` cannot satisfy the formal `1080p` floor even with `native_720p_scene`). Use `scripts/gemini_api_cli.py video --resolution 1080p` or tail-frame `Frames` conditioning on `1080p`-upscalable single clips, or report verified `720p` platform limits honestly rather than silently lowering targets.

## Build a cloud-generated narration master for each language

Adapt approved Chinese narration into natural, active-voice spoken English preserving exact causal order, units, and conditions — using native curiosity pivots (`"By all rights..."`, `"Except one tiny detail breaks that:"`, `"Which triggers an immediate snag:"`) rather than passive textbook calques or `Furthermore`/`Moreover` lists ([claim preservation](science-and-rights.md#preserve-claim-meaning-through-production-handoffs); [spoken craft](voice-reference.md#edit-narration-and-dialogue-for-the-ear)):
- **Warm conversational paragraphs, zero per-shot chopping, 0–8 s single-paragraph onset:** Draft cohesive paragraphs (not per-shot `\n\n` couplets), keeping the entire 0–8 s hook + viewing promise inside **one continuous opening paragraph** so no dead stall lands at 3.5 s. Keep scripts free of blunt/confrontational wording (`凭什么`/`凭啥`/`偏要`/bossy imperatives/crude verbs), prompt colons, coined shorthand, early static structure dumps, premature ending signals, or slogan closings. Synthesize continuously (`duration_factor=1.0`, `use_emo_text=False`, automatic edge-silence trimming enabled in `synthesize_indextts2.py` for `#5` IndexTTS-2.5; `|rate| <= 6%`, default `+4%` for `edge-tts`), keeping natural cadence, inspecting `engagement_diagnostics` in `prepare_voice_master.py`, reserving `0.25–0.45 s` solo foley micro-breaths ahead of key pivots plus `>= 0.8 s` wordless observation holds on `2–4` major reveals (`>= 15%` of shots), and using anti-spoiler caption splitting across `——` and reversal pivots. Snap cuts to natural breath valleys with `0.12–0.30 s` J/L overlaps and `0.20–0.30 s` act-boundary dissolves; keep continuous `150–250 ms` room-tone/foley crossfades (never digital zero) and `-16 LUFS` / `-1.5 dBTP` mix balance. Optional [Flow Music](https://support.google.com/flow/answer/17084348?hl=en) or `gemini-api music` (`lyria-3.5`) stays on its own ducked stem within verified plan/API rights.
- **Canonical audio bindings:** Default Chinese `#5` clone binds `voice_type="synthetic"`, `mode="local_project"`, `provider="IndexTTS"`, `backend="local_indextts2"`, `model_id="IndexTeam/IndexTTS-2.5"`, `speaker="user_clone"`, plus `postprocess_record` (`whole_track_speech_polish`); `edge-tts` English / cloud ZH fallback binds `mode="service"`, `provider="Microsoft Edge"`, `backend="edge-tts"`, `model_id="edge-tts"`; optional `gemini-api tts` (`scripts/gemini_api_cli.py tts`) binds `mode="service"`, `location="https://generativelanguage.googleapis.com/v1beta/interactions"`, `provider="Google"` (or `"Google Gemini API"`), `backend="gemini-api-cli"`, `model_id="gemini-3.8-flash-tts"`. Never record `Qwen`, `synthesize_voice.py`, or `os_tts`.

## Edit, mix, caption, export and review in Flow

- Maintain clause-level single-line synchronized subtitles (`.zh.srt` `WrapStyle=2 >= 20 pt`; `.en.srt` `WrapStyle=0` clean breaks, zero SSML/markup leakage).
- Generate clean text-free cover art (`3:4` & `4:3`, plus `16:9` if requested — via `scripts/gemini_api_cli.py image --image-size 2K` or Flow Web) and render separate `zh` and `en` covers strictly via `scripts/compose_cover.py --lang zh|en` (never reuse Chinese cover text on English editions).
- Enforce `>= 1080` short edge (`1920×1080`, `24/1 fps` CFR) on all formal samples and finals under [HD output](quality-acceptance.md#hd-video-output); report genuine route blockers honestly without bypassing tool boundaries.

## Audit staged clips and paired editions before delivery

Bind staged cloud clips (`ai_generated`), prompt-ledger proofs (recording `gemini_api_cli` interaction IDs or Flow Web card indices), and audio stems into sibling `episode.zh.json` and `episode.en.json`, then run:
1. `python -X utf8 scripts/google_flow_audit.py measure <zh.mp4> --episode-zh <episode.zh.json> --en-video <en.mp4> --episode-en <episode.en.json> --clips-dir <clips-dir> --report <flow-audit.json>`
2. `python -X utf8 scripts/opening_hook.py measure <export.mp4> --captions <srt> --preview-dir <dir> --report <hook.json>` (both editions)
3. `python -X utf8 scripts/realistic_audit.py measure <export.mp4> --shots <shots.json> --delivery-fps 24 --report <realistic-audit.json>` (both editions)
4. `python -X utf8 scripts/check_episode.py <episode.zh.json|episode.en.json> --stage delivery --report <delivery.json>`

Follow checks with independent `1.0×` continuous audiovisual review in BOTH Chinese and English, preserving SynthID provenance and platform AI disclosure ([publication declarations](production-checkpoints.md#declare-ai-generated-content-at-publication)).

### Diagnose by symptom

| Symptom | Root cause | Fix |
| --- | --- | --- |
| `1280×720` clip / scene | Bare `gemini-api video` omitted `--resolution` (defaults to `720p`), or Web UI downloaded `720p Original` / `>> Extend` / `Download scene` | Generate via `scripts/gemini_api_cli.py video --resolution 1080p` (or `4k`), export Flow single clips via `1080p Upscaled`, chain via tail-frame conditioning, or report `720p` blocker |
| `gemini-api` exit `3` or `unauthenticated` preflight | Missing `GEMINI_API_KEY`, keychain credential, or OAuth token | Run `scripts/gemini_api_cli.py preflight --check-auth`, configure API key (`GEMINI_API_KEY` or user-run `gemini-api configure`), or fall back to Google Flow Web UI |
| Inline `--input` rejected (`> 14 MB` / `20 MB` base64 cap) | Large local reference video/image exceeded CLI inline request limit | Use `scripts/gemini_api_cli.py video` (auto-uploads via `files upload --wait`) or upload once via `scripts/gemini_api_cli.py upload <file>` and pass `files/<id>` |
| `gemini-api video` timeout / disconnected poll | Network drop or long render exceeded poll window | Inspect `--ledger` for saved `response_id` and recover via `scripts/gemini_api_cli.py resume <id> --out <clip.mp4>` (never blindly resubmit) |
| 4th-frame judder | `24 fps` Flow/Omni clips forced onto `30 fps` timeline | Lock `design.output.fps=24` CFR & pass `--delivery-fps 24` |
| Slow-mo / tail freeze / warped foley | Beat exceeded `~7.0 s` usable core | Split into `SHxxA`/`SHxxB` or tail-frame conditioning bridge; remove `setpts`/`tpad`/`atempo` |
| Stiff/blunt tone, pitch resets, or dead gaps | Per-shot `\n\n` breaks, `\|rate\| > 6%`, blunt/telegraphic wording, or spliced `1.5–2 s` holes | Rewrite warm paragraphs ([voice-reference.md](voice-reference.md#edit-narration-and-dialogue-for-the-ear)), synthesize continuously, add `0.12–0.30 s` J/L cuts & continuous room tone |
| `Audio generation failed` (`30–57%`) | Offscreen Mandarin speech prompted in Veo 3.1 | Prompt physical foley only in Flow/CLI video prompts; mux continuous `#5` IndexTTS-2.5 / `edge-tts` narration |
| `"We noticed some unusual activity"` | Parallel Web UI tabs or rapid polling | Stop immediately (never bypass); resume 1-by-1 serially or switch to authenticated `gemini_api_cli` |
| Missing `Scenes` / `+ Add clip` | Browser pane `< 840 px` (mobile mode) | Lock viewport `>= 1440×900` on every step |
| Garbled dials, PiP borders, late morphs, or body horror | Asked for labels/insets, unchecked `4–8 s` tails, or carved/translucent skin | Use blank frameless props, intact exteriors + non-fleshy microscopic cuts, full-res `1920×1080` inspection |
| Clashing chatter / `zh` vs `en` cover mixup | Unmuted baked gibberish audio or reused `zh` cover | Mute gibberish clips, layer clean foley, run `compose_cover.py --lang en` separately |
