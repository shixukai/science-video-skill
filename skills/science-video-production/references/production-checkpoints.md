# 从研究到可执行的制作检查点

用于写脚本、做代表性小样和验收本集。以下是结合研究与本项目经验的实施建议，不是整套经实验验证的配方；不保证播放、完播或涨粉。按本集实际画面、声音和观众反馈调整，不能只勾选表格。

## 1. 先确定观众要看懂的一件事

在 brief 写三句：观众见过什么、哪里值得问、看完能解释什么。单集围绕一个日常核心问题，结尾回答开头。先列理解该原因所必需的对象、部件或状态；不熟悉的词在对象出现时用一句日常话解释，不强塞名词表。

先检查片内开场能否自然告诉观众本期主题和继续看的具体收获，再承接首个解释镜头。允许“现象钩子 → 主题一句 → 解释”或主题先行，口播与简短标题配合；标题仍叠在满幅画面上，不另造长片头或大标题板。不固定秒数或套话，发布简介也不能替代片内主题交代。若开场只有突兀实验/术语而没有承接，先改开头。

产物：一句问题、简短答案、必要前提。若答案仍只是术语或比喻，或听懂它还需另查背景知识，先改脚本，不进入批量制作。

## 2. 把因果变成可见变化

每个必要解释镜头在分镜中写：之前状态 → 改变因素 → 结果，再写对应口播。让观众看到哪一个因素导致哪一个变化，外观转场或物体乱动不能冒充机制。

同一对象跨镜头保持可追踪的身份、颜色和空间关系；放大、剖面或视角变化先交代与整体的关系。标签放在对应对象附近，强调只跟随正在讲的因果步骤，口播与该变化同时发生。必要的放大、变速、模拟按实际情况标示。

产物：可逐行对照的因果分镜。缺少前因、对象突然变了含义、标签找不到对象、画面没有表现口播所说的变化，都先修分镜。

### 逐段声画与图内文字对应

对每个完整解释语义段写一行对应关系：实际口播句 → 被讲述的画面对象 → 对象动作或状态变化 → 必要时的就近图内短标签/关键词（无需添加时注明画面如何讲清） → 真实音轨时点与最终导出证据。按语义段而非每个字强制动画；字幕、图内解释与主题标题各有职责。

- 说部件或对象时，让观众在主画面定位它；必要时高亮或移动视线引导，标签贴近所指对象
- 说变化、比较或因果时，展示前态、变化因素与后态；口播提到的变化与画面事件同时对应，不能提前显示下一阶段结果
- 必要图内文字简短解释正在看的动作、关系、条件或数值，术语与口播一致；先做文字删除测试，不为每段配字。主图必须承载对应解释，不能只有底部逐字字幕在更新，也不应复制整段旁白造成重复阅读
- 同一对象跨镜保持身份与含义；局部放大、剖面、视角或类比切换先交代关系。类比不能代替真实机制，也不能把类比结论直接当完整解释
- 开场必须有明确的片内主题陈述，说明本期要解释的现象/问题；现象钩子、疑问或画面标题本身不能自动算作已经明确交代。允许自然措辞，不强制固定问候、句式或秒数

验收先静音检查主图和图内文字能否让人定位对象、变化与关系，再带声连续逐段对照口播、动作、标签及字幕的真实时点。静音检查不是要求画面独立讲完全部细节，带声检查也不能仅以转写或时间码匹配代替。记录检查版本、时间点、实际对应结果和缺项；填写映射表不创造验收事实。用户指出解释混乱或声画脱节时，当前内容验收失败：重查因果与分镜，不只补一句片头或修改底部字幕后沿用旧通过。

## 3. 先做代表性解释小样，再做整片/整批

选本集最难讲清、最能检验视觉方案的一段，实际渲染包含“之前—变化—结果”的连续片段，配对应真实解说、字幕、图例和系列样式。2D解释都走这一步；封面、静态概念图或工具参数不能代替动态小样。

按 [质量验收](quality-acceptance.md) 先用少量关键帧对照可追溯专业参考，核整体、关键细节与功能，再做约10–20秒或足够覆盖机制变化的短样。不是达到某个时长即通过，也不把“精美”当签收词；已发现的造型、线条、色彩、排版、空间关系或连续性缺陷须先退回修复。

先检查解释是否成立，再精修2D造型、线条、色彩层次、排版、几何/箭头、运动和字幕。用实际导出看原尺寸和手机大小代理图，并看连续播放中的变化；代理缩图不称为手机实测。发现问题先修小样，不能把未看过的样式批量复制。

布局分层检查：用最终导出宽高确定几何中线，主体默认视觉居中；检查完整轮廓、光学重心和留白，子画布坐标不能当整张画布坐标。主体/图内标签与字幕/平台覆盖区分开安排，不能为避开 UI 而整体缩小或向左上挪出大片空白。必要偏心须记录叙事理由。保留代表小样的修前/后实际帧，在首/中/末、运动端点与极值看位置和连续运动；用户指出偏位后，对应旧视觉通过改为待复核，不能沿用到新批次。

产物：短样文件和具体查看结果/问题时间点。不会渲染、看不到实际帧或听不到对应声音时，分别标缺项；不能用文字想象签收。小样无须固定秒数，须覆盖需要检验的解释。

## 4. 按真实解说安排理解节奏

先保全必要机制，删掉支线与重复，再用实际配音安排镜头。难点后给观察、对比和消化的停留；不能为固定总时长删关键因果或加速 Qwen 硬塞。

难点出现时降低无关粒子、背景运动、切镜和抢耳音乐。保留必要的中文可访问性字幕，不把“减少冗余”误用为删字幕；同时避免又叠一段重复正文。精美与清楚要同时达到，少元素并不自动等于高质量。

## 5. 五类结果分开写，证据不能互相代替

- 事实：关键主张与权威依据匹配，模拟/类比的边界清楚；有事实错误先改
- 理解：编辑可检查前提、术语、因果覆盖与同步。若有已获授权的真实试看，让对方复述问题与原因、回答一个简单条件变化问题，并指出首次困惑处；记录实际答案，不诱导照抄。没有真实反馈写“编辑自审；理解效果待验证”，模型扮新手只能帮助找疑点
- 美术与声音：看/听当前真实导出，检查连续变化、文字可读、系列一致、自然口语、字幕与混音；不能靠渲染代码或少数静帧代替全片
- 技术：文件流、尺寸、完整解码、时长、首尾音画完整；通过只表示这些项目通过
- 平台：按下一节检查实际账号、最终文案和实际界面；本地播放器通过不能代替

每类只写实际对象/版本、所用方法、看到或听到的结果、仍未检查的部分。真实观众明确看不懂是内容失败；模型自评、ASR、SSIM、帧差、音量、点击和完播不能盖过该失败。小样本试看用于发现问题，不包装成总体理解率或有效性证明。

`qa.comprehension.status` 用 `pending`、`editor_reviewed`、`audience_checked` 或 `fail`，不得直接自填 `pass`。编辑自审可支持继续制作，但须写清真实理解效果待验证；只有实际观众反馈才能用 `audience_checked` 并提供反馈引用。已知看不懂用 `fail`，不能被技术通过忽略。

用户指出某版本的具体质量问题后，对应旧通过失效：待查时将该项改为 `pending`，已确认缺陷改为 `fail`，在 note 记录版本与问题。修复后凭当前导出重新检查才能恢复有效结果；不能只在旧 `pass` 后补备注，或把别的版本的认可挪过来。

若用户整体否定一批，冻结该批当前交付/发布资格并撤回相关有效通过，先检查共同根因，不限于用户点名的局部。用参照对比与新代表小样证明修复范围后再评估各片；修改规则或让测试变绿不会自动解冻。已认可且仍适用的音轨保留，已发内容不自动改动。

## 6. 从导出到实际平台完成检查

只有已获所需上传/预览授权时才进入平台。使用实际目标账号，填入最终标题、完整简介与 tag，等平台 UI、文案和预览真正加载；保留用户名、互动栏、文案等实际覆盖区域，查看首/中/末、最密字幕、转场及运动极值。文案长度可能改变遮挡，不能只用短标题预览代替最终文案。

记录预览来源：实际手机/平台发布页预览/本地播放器，以及导出版本、最终文案和关键时间点截图。浏览器中的手机样式预览不能称为实机；被截图裁去画幅边界时不能反推完整 9:16 坐标。没有实机条件就写未做实机检查。

发现关键字幕、单位、标签或主体被挡住时，做最小布局调整，重新导出并在同一最终文案/界面下复查，不能沿用旧通过记录。改视频、标题、简介、账号或相关展示方式后重查。没有平台访问或授权时可交待平台检查版，不能宣称已完成平台适配，更不能自行发布。

在 `qa.mobile_preview` 记实际 `platform`、`account`、`review_scope=target_platform`，`surface` 用 `actual_device` 或 `desktop_platform_preview`，`note` 记录看到的结果与截图/时间点；裸播放器或代理缩图不能填成它们。实际复核后再填 `reviewed_metadata_sha256`，由本地 `check_episode.py` 的 `platform_metadata_sha256(data, preview)` 对标题、简介、tag、平台、账号与预览来源计算，缺失时检查器会显示当前值。计算/复制哈希不代表验收；它只帮助发现后续文案或目的地变更使旧记录失效。

## 研究依据与适用边界

- [National Academies，2017，Summary](https://www.nationalacademies.org/read/23674/chapter/2)：委员会框架强调目标、受众和情境；不是“单条一问”或日常题必胜的实验。本节单一问题做法是实施取舍
- [Mayer 等，2002，预训练实验摘要](https://pubmed.ncbi.nlm.nih.gov/12240927/)：学生观看制动器/气泵动画，先认识部件状态有助迁移测试；不是中文自然短视频平台试验
- [Mayer 与 Moreno，2003，证据总结，第46–48页](https://carpentries.github.io/instructor-training/files/papers/mayer-reduce-cognitive-load-2003.pdf)：支持减少无关加工、提示与标签邻近、声画对应。它不是单一新实验，不能直接推导删字幕或固定切镜时长
- [Mayer 与 Chandler，2001，分段实验](https://tecfa.unige.ch/tecfa/teaching/methodo/Mayer_Chandler01.pdf)：研究学习者可控节奏的闪电动画与迁移表现；不是固定视频暂停长度的直接证明，分段与交互/学习时间须区分
- [《The Green Planet》制作人访谈，2022](https://www.thenakedscientists.com/articles/interviews/green-planet-filming-secrets)：研究故事与开发拍摄技术并行，技术用于显露过程；属第一手制作案例，不能证明某种媒介必然更易懂
- [KQED Cracking the Code 项目总结，2022](https://www.kqed.org/about/16895/cracking-the-code-millennial-science-media-habits-and-engagement)：结合调查、实验与实践，提示区分受众、平台和指标；点击/意向/投入不等于理解，也不能直接外推抖音涨粉
- [TikTok In-Feed Ads，Safe Zone](https://ads.tiktok.com/resources/help/article/tiktok-auction-in-feed-ads?lang=en)：截至2026-10-06所读版本说明安全区受画幅、简介长度和附加形式影响，预览与实际设备可能不同。这是 TikTok 广告文档，不是抖音自然投稿硬标准；本项目仍以实际抖音界面验证，不固定通用像素线
