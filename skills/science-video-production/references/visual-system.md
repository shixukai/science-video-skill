# 视觉与声音系统

首次定系列、做封面/关键帧或修改质感时读本页。既有系列设定优先；下列是起点，不是已批准的品牌规范。

## 保持识别，允许题材呼吸

在单集 brief 中简记 5 个系列锚点：系列名/小标记、字体层级、主中性色与单一强调色、字幕样式、声音语气。不要每集重做身份，也不要让片头模板占满注意力。

可先试：接近自然纪录片的色彩、克制的暖白字、深灰文字底与一个低饱和强调色。只有概念需要时才加入强调图形；避免霓虹满屏、随机图标、每句都放大弹跳。字体、音效、音乐和标志本身也需要可用权利。

系列识别最好来自重复的排版关系与声音语气，而不是一个巨大 logo。开头直接进入现象，系列名或集数小而稳定地出现；结尾回扣问题即可，不强塞“关注点赞”。

片内第一屏同时让人认出“对象/现象”和“这一期具体要问或讲什么”：主视觉与主题直接对应，标题层级醒目、高对比，手机大小第一眼能读清。选合适的字体、描边或局部遮罩，不把某一款粗白字、倾斜样式或固定秒数当模板；标题仍叠在满幅场景上，不做独立大黑板，也不靠夸张承诺吸引人。

检查实际导出的开场：不看封面/简介也能认出主题，连续播放时标题有自然阅读时间而非一闪而过；带声检查主题口播和画面标题在讲同一件事，并顺畅进入首个解释镜头。仅封面主题明确、片内没有对应第一屏，不能算通过；逐段声画与图内文字对应要求继续保留。

## 纯2D解释与真实素材

- 围绕主题相关、有权真实素材中的对象/现象创作，素材在合适位置承担观察或解释作用；开头优先用，但不强制位置和秒数。2D用于标注、放大、剖面、空间和不可见机制，需与真实对象连贯对应，不作装饰插入
- 原理讲解统一用纯2D插画与动画，不用3D模型渲染或伪3D模型。按专业参照核造型比例、关键轮廓与结构；线条粗细/端点/接缝一致，色彩分出主体、作用因素与背景，科学颜色含义不能乱换；排版让对象、短标签与解说字幕各有层级
- 用2D剖面、分层、局部放大与连续状态变化解释关系；形体、线条、颜色和对象身份跨镜一致。纹理、渐变和阴影仅在帮助理解时使用，不以堆光效伪装体积；运动平顺且对应因果，不能靠无意义旋转、粗糙几何拼贴或机械文字轮播交差
- “精美”、工具名称、图层数与特效数量都不是验收结论。执行 [参照式质量验收](quality-acceptance.md)：并排记录参照与导出的造型/结构/线条/色彩/排版/连续运动差距、依据及退回处理；不虚构审美分数，不能只喊“更精美”而没有具体修复
- 选择实拍时，关注真实材料细节、自然光影、尺度参照和适度景深；先解决焦点、曝光、白平衡、抖动、背景杂物
- 科学色彩有含义时保留原始色彩。伪彩、加速、慢动作、合成、去噪或夸大比例会改变理解时注明
- 裁切不能去掉证明事实的关键上下文；不能为“大片感”变形、补造数据或加不存在的现象
- 2D可以承担完整机制解释，与真实现象在对象、颜色和关系上连贯对应；按解释需要决定占比，不限定图解只能少量补充
- 面向普通大众时，先让人认出正在解释的自然现象或日常对象，再用图解辅助理解；避免只给抽象点阵、统计分布或符号而让观众猜主题。需要数字比较时保留清楚的对象、单位和一句生活语言解释，不把画面变成数学课
- 各种形式都须科学准确，物理比例、时间、路径若非按比例，相关处标“示意，非按比例”；不得把图解、模拟或生成画面当实拍证据

## 竖屏满幅画面

9:16 成片的实际视觉场景须铺满画面，不只让容器尺寸达到竖屏。禁止为标题或系列名专门预留大片独立黑/深色板；标题、字幕叠在场景上，按实际明暗在文字附近用适度半透明底或轻遮罩保证可读，不把遮罩扩成新的整块标题区，也不把主体与字幕整体缩小/上移腾地方。

满幅不能以破坏内容为代价：不拉伸比例，不裁掉科学关键主体、脚点、接触位置或理解机制所需的上下文，不单为填满而补造影像。无法在这些条件下安全重构时，换合适的有权镜头或按教学目的另做明确标示的 2D 方案。素材本来的宇宙、夜空或阴影暗区应保留并与排版生成的人工黑边区分，不能把所有暗像素都当失败。

2D 用连贯场景铺满，延续与内容有关的空间或环境；不靠无意义粒子、装饰或单纯扩大深色底板假装满幅。主体光学居中、满幅构图和字幕/平台 UI 安全区分别检查，不能牺牲其中一项来假称另一项通过。

看实际导出首/中/尾、转场及运动极值，并连续播放：是否仍有人工大标题板/黑边，文字遮罩是否局部，科学关键部分是否完整，构图是否自然。输出分辨率正确、外框居中或解码成功不能代替此检查；平台上的字幕遮挡仍须独立验证，用户未理解的内容也不会因铺满而自动合格。

## 文字、居中与运动

字幕通常一到两行，按语义断句，不拆数字单位和术语；对明暗变化大的真实画面用克制的半透明底或细描边。通过手机阅读速度判断停留，而非只按配音时间平均切字。

解说字幕应在实际画面下方，不与主体争占中心；这是与图内标签不同的层。以实际全帧、小屏和最终完整平台UI核最长两行及换句，确认确在下方、清楚可读且不遮关键内容。不能拿一个通用Y坐标/百分比称为“已居下”，也不能为躲UI把字幕挪到画面中部或整体缩移场景。

字幕背景按最终排版的真实字形测量：使用实际字体、字号、行距与描边渲染或测量可见外缘，再加必要的水平/垂直 padding。背景宽度跟随实际文字宽度，高度跟随实际行数与字形总高度；短一行不套两行大框，不为所有句子统一使用最大宽度，更不能只按字符数估算。圆角、透明度、padding 和锚点按本片设置，不把某次样片像素当跨片常量。

文字与背景几何分开处理：在本片选定的字幕区内固定水平中轴与末行基线等明确阅读锚点，背景尺寸变化不重新定位字层。可按完整字幕段缓存稳定布局/叠层，同段各帧复用，仅换句时更新；避免逐帧重算造成抖动或无关伸缩动画。超出可读宽度时先合理断行/分句，不靠缩小字号省背景，也不越过平台安全区。

实际导出分别检查短一行、接近宽度边界的长一行、两行、短长句切换前后，并看连续片段；核对字形/描边不被切掉、padding 适度、基线稳定、字号与停留时间可读。亮/暗背景下的对比和最终平台 UI 遮挡另验。两张样帧或一种暗背景通过，只能说明这些样例，不能宣称全部边界、背景或整片已通过。

主体默认视觉居中。先读取实际导出的画布宽高，确定整张画布的几何中线；不能把子画布或贴入素材的中心当整片中心。再看完整轮廓、光晕、明暗重心及四周留白，几何中心不等于全部光学判断。非居中构图必须有明确叙事理由并看实帧验证。审片辅助线不能混入成片。

主体、图内标签、字幕与平台 UI 覆盖区域分别布局。安全区修复不能靠把主体和字幕整体缩小、左移或上移来完成，否则容易造成偏位和大片空白；优先局部排版，保持主体重心。以代表小样的修前/后导出帧检查首/中/末及动态端点/极值，再批量应用；仅代码坐标正确或静态框不越界不能签收。用户提出偏位时，撤销对应版本的视觉通过并重新核对。

将字幕、主体关键部位、单位、真实性标签放在当前平台界面的可读安全范围。右侧交互栏、底部文案、顶部状态和不同机型会变；按实际预览建立遮挡模板，不把一个像素常数当永久安全区。

可操作的顺序见 [生产检查点](production-checkpoints.md)：代表性因果短样先检查，再做整批；标签靠近对象，放大/剖面与整体保持可追踪关系，动效跟随正在解释的变化。最终平台检查须带实际账号、完整最终文案和已加载 UI；长简介可能增加遮挡。被裁切的预览截图不能反推完整画幅像素，360宽代理也不能称实机。调整布局后重新导出、重新预览。

检查整个动画轨迹及缓动超调，包括开场入画、中途最大缩放、描边/阴影/光晕最外缘、出场。抽帧覆盖每镜头、字幕变化和极值；复杂快动段应逐帧或慢放复核。主体刻意偏心不算错误，但不能误称居中。

## 观众画面与交付记录

画面文字应帮助观众理解当下内容，或满足必要的真实性/许可/平台标注要求。标题、同步字幕、必要术语解释、图例、单位和条件可以保留；不要把制作、测试或验收记录当成观众需要的正文。

一般来源条和制作方式说明默认放配套资料或简介，不作为固定页脚反复占用画面；画面文字的删改不自动授权改动已认可的叙事。

完整科学来源、素材权利、合成语音与制作声明仍须随交付提供。许可规定必须出现的署名，以合规且克制的形式保留；相关镜头中防误认的“机制示意，非按比例”“模拟画面”“AI生成画面”，以及平台要求的披露不能为了画面干净而删除。合成声音声明移入配套不代表可省略必须显示的平台标签。

导出后逐镜读完全部烧录文字，覆盖片头/片尾、字幕、角标、图例、页脚与短暂转场。排除制作流程、版本号、测试/验收/待审状态、内部备注、模型/工具清单和流水线说明；不要将简报或台账字段整批渲染。来源或必要标签有疑问时核对其用途与要求，不能一键删除全部角标。

## 两种封面各自设计

3:4 和 4:3 共用视觉身份、事实和主要素材；标题行数、主体尺度、留白、标记位置分别调整。先看手机缩略图是否能读到主标题，再看大图细节。两个不同画幅的导出文件不等于已分别排版，人工确认不能省。

封面问题不能比正片结论更夸张；不用危险假效果、捏造比较或误导的实验前后图。可用同一条可靠素材中的不同帧，不要求每次重新生成图片。

## 声音质感

每条必须有中文语音解说，保持干净人声、场景自然声和细致留白；配乐可没有。纯字幕加配乐只算待补录。首次先交一条音色和节奏试听，再按该系列方案制作；记录试听文件/消息引用及已有反馈，后续沿用，不强制每集重复选声。

当前用 Qwen 已获认可的自然口语方案，参数与认可范围见 [语音参考](voice-reference.md)。目标是像认真向朋友解释：有语义轻重和自然停顿，普通话清楚，避免播报/朗诵腔、逐字停顿或每句同一种起伏。模型名称、响度达标或解码成功不能证明自然。Qwen 不可用时报告阻塞，不擅自换回已拒绝的声音或改付费服务。

先把术语、数字、单位、多音字写清并试读，再按自然语义安排重音和停顿；字幕逐句跟随实际口播，不提前泄露后句或滞后到下一镜。不能为了固定时长压缩到赶读。避免每次切镜都加 whoosh、心跳或警报；不可录到的设计音效不暗示为真实录音。

短稿尽量连贯生成；长稿按服务能力与完整语义分段，不机械逐词切分后拼接。逐段核对读音、停顿和声线，再听连接处及全篇节奏。不要把短样获认可推广成整条或整批已通过，也不要用混响、配乐或改速掩盖生硬。

声音电平先实测再设目标，保证人声清楚、无削波，切换无突变；配乐在人声出现时降低，不能遮盖解说。手机扬声器与耳机实听完整导出，核对发音、节奏、字幕同步和混音；不能只靠音轨存在、语音识别、波形或响度数字签收。无法实际试听时写“未验”，不得填通过或宣称完整交付。

记录实际听过的对象和范围：短样、单段语音、完整语音或当前混音视频。`qa.narration.review_scope=final_export` 只对应当前完整视频；先前短样的认可与当前成片的自然度/字幕/混音验收分别记录。

合成旁白在制作声明中如实标为合成声音，不称真人录制，不克隆真人；使用有权音色，不擅自付费购买服务。缺配音能力就交待补录版并说明缺项。
