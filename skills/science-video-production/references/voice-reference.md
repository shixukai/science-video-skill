# 中文解说技术参考

默认采用 Qwen 自然口语方案。下列配置是制作起点，不代表使用者的样片或成片已获认可；正式生产前须独立试听并记录本项目反馈。服务不可用先报告阻塞，不擅自改变已确定的声音方案或换付费服务；后续需要时可按明确指示更新方案。

## 配置引用

当前模型、音色、语言和指令见 [系列配置](../config/series-profile.json)，不在本页维护第二份项目参数。模型参考：[Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice)；接口参考：[Qwen官方演示](https://huggingface.co/spaces/Qwen/Qwen3-TTS)，`generate_custom_voice`。首次使用或服务变更核实际接口/条款，不凭旧示例猜能力或缺省参数；记录实际版本/权重修订，模型名不保证逐字节复现。已有项目确认参数与仍匹配音轨保持，不为迁移重生成。

## 生成与后处理示例

短稿可按完整语义整段生成 WAV，再转 MP3。可试用的响度/编码起点见系列配置的 `audio.postprocess_example`；先实测电平并实际试听后决定是否适合本片。这不是通用响度标准，也不能修复生硬语调；不要用改速、变调、混响或配乐掩盖问题。

首次交付试听时记录样片、配置、实际反馈与认可范围；私有素材引用、反馈原文和授权记录留在本项目非公开台账，不写入通用 Skill 或公开示例。短样认可只覆盖所听样片，不能代表长稿或混音成片通过。

## 长稿仍须检查

沿用本项目试听确认的音色与口语指令，按连贯语义生成；超过服务能力时按完整段落拆分，避免机械逐句拼接。每段核对与稿件一致、无漏词/重复/跑词，检查术语、数字、单位、多音字、停顿、音色及拼接处，再实际试听整段语音和当前完整混音视频中的字幕同步、自然度及混音。每条须中文解说，缺能力就交待补录版；字幕配乐不能冒充配音。配乐为人声让位，逐段/跨段核突刺、削波、突断，不用whoosh或警报覆盖问题。手机扬声器/耳机按实际条件记听过的设备范围，不伪称已做双环境；音轨存在、ASR、波形或响度不等听过。没有实际试听就留“未验”；不能用短样认可代填 `qa.narration` 通过。

异常时长或疑似文本偏离要先拦截核查，不直接装片，不猜模型根因。完整解码、时长看似合理或 ASR 文本对齐，都不能代替真实听感和文本正确性检查。

声音方案发生实质变化时重新交短样听音色与节奏。不得擅自克隆真人；合成声音如实声明，画面披露遵循既有必要标签和配套资料规则。

## 默认方案与传输授权分开

选择某一配音方案不自动授权向服务发送任意内容、视频或参考声纹。每次使用前核对文本、接收服务、目的与授权范围；更换目的地、数据类别或用途时重新确认覆盖，不能把仅文字的授权扩大到视频或参考声音。

遇到服务或配额失败，报告具体阻塞，不能轮换账号、换镜像或使用其他方式规避限制，也不能自动购买额度。只在已有权限内使用正常恢复方式。不要在台账或仓库存入凭据、令牌或参考声纹。

使用前核对模型发布页及实际服务条款；模型许可不等于所有服务、音色、数据传输和输出用途均自动获准。本页技术参考也不代替任何所需授权。

## 完整听检硬门槛与混音起点

正常速度完整听当前最终成片，耳机与手机外放两种环境均必做，记录设备类型、版本、区间及具体问题时码；缺一种就该项未验，不以工具/环境不足签双环境通过。平台预览另核关键段。核心术语错读、因果连接词吞漏、断句改义、拼接突变、持续底噪/失真及音乐遮解释均退回。实际混音文件而非仅WAV或ASR是最终对象。

主题、因果动词与结论有自然重音，给定位/变化留观察停顿；长句先改稿，不统一放慢成机械讲述。配音、配乐、环境与音效分轨；配乐不得盖句末/轻声，不每次切镜默认加音效。关键音效与事件对齐，不可听过程的设计声音不能冒充原声记录，按必要边界说明。

完整标准的混音、语速与编码D起点见制作策略；系列已有认可配置/可用音轨优先，不为-16LUFS或220–270字/分钟数字强制变速、改声线、重生成。最终编码实测响度/峰值，数值不是平台官方要求也不代听检。剪接、补录、改词、停顿/语速变化都新建音轨版本并重核实际时码、字幕、关键动作与完整混音。

模型名称/Serena默认、精确权重或服务修订与本项目运行配置分开：系列配置提供默认模型/音色/复用政策，narration.config_reference指真实运行记录，exact_model_revision_reference只填实际取得的精确修订依据；未定位写未定位，不发明版本也不为补记录重生成。

声音样本或独立源音轨在 `narration.source_listen_review` 记录自己的file/hash、scope、实际所听区间/方法/能力和证据；最终混音听检仍在qa.audio.listening。样本WAV、完整原声和最终视频不能默认为同一文件。解析当前音轨路径必须由narration.asset_id匹配assets[].id再取file/hash，不能取数组第一个资产或把配置引用当音频。
