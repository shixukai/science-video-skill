# 中文解说技术参考

默认采用 Qwen 自然口语方案。下列配置是制作起点，不代表使用者的样片或成片已获认可；正式生产前须独立试听并记录本项目反馈。服务不可用先报告阻塞，不擅自改变已确定的声音方案或换付费服务；后续需要时可按明确指示更新方案。

## 示例配置

- 模型：[Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice)
- 接口参考：[Qwen 官方 Hugging Face 演示](https://huggingface.co/spaces/Qwen/Qwen3-TTS)，`generate_custom_voice`
- `language`: `Chinese`
- `speaker`: `Serena`
- `model_size`: `1.7B`
- `instruct`：自然口语，像认真向朋友解释一个有趣现象。第一句带一点好奇，接着平实讲清因果。不要朗诵腔，不要逐字停顿，句子有轻重变化，普通话清晰。
- `text` 只填入已获对应传输权限的稿件；本参考不包含待发送稿件
- 此示例未指定 temperature、top_p、seed、speed 等参数，不推断其默认值。正式使用时核对实际接口、记录可得的版本或权重修订号；模型名不能保证永久逐字节复现

参考参数顺序为 text、language、speaker、instruct、model_size。首次使用或服务变更后核对接口，不凭旧记录猜测当前能力。

## 生成与后处理示例

短稿可按完整语义整段生成 WAV，再转 MP3。可试用的 ffmpeg loudnorm 目标为 `I=-18:TP=-2:LRA=7`，48 kHz、192 kbps；先实测电平并实际试听后决定是否适合本片。这不是通用响度标准，也不能修复生硬语调；不要用改速、变调、混响或配乐掩盖问题。

首次交付试听时记录样片、配置、实际反馈与认可范围；私有素材引用、反馈原文和授权记录留在本项目非公开台账，不写入通用 Skill 或公开示例。短样认可只覆盖所听样片，不能代表长稿或混音成片通过。

## 长稿仍须检查

沿用本项目试听确认的音色与口语指令，按连贯语义生成；超过服务能力时按完整段落拆分，避免机械逐句拼接。每段核对与稿件一致、无漏词/重复/跑词，检查术语、数字、单位、多音字、停顿、音色及拼接处，再实际试听整段语音和完整导出视频中的字幕同步、混音与自然度。没有实际试听就留“未验”；不能用短样认可代填 `qa.narration` 通过。

异常时长或疑似文本偏离要先拦截核查，不直接装片，不猜模型根因。完整解码、时长看似合理或 ASR 文本对齐，都不能代替真实听感和文本正确性检查。

声音方案发生实质变化时重新交短样听音色与节奏。不得擅自克隆真人；合成声音如实声明，画面披露遵循既有必要标签和配套资料规则。

## 默认方案与传输授权分开

选择某一配音方案不自动授权向服务发送任意内容、视频或参考声纹。每次使用前核对文本、接收服务、目的与授权范围；更换目的地、数据类别或用途时重新确认覆盖，不能把仅文字的授权扩大到视频或参考声音。

遇到服务或配额失败，报告具体阻塞，不能轮换账号、换镜像或使用其他方式规避限制，也不能自动购买额度。只在已有权限内使用正常恢复方式。不要在台账或仓库存入凭据、令牌或参考声纹。

使用前核对模型发布页及实际服务条款；模型许可不等于所有服务、音色、数据传输和输出用途均自动获准。本页技术参考也不代替任何所需授权。
