# 按制作场景调用工具

`science-video-production` 负责整期内容与交付。主制作工具严格按[成片风格](#按成片风格锁定主制作工具)分流：写实风格使用 MoneyPrinterTurbo，3D动画风格使用 Blender。题材和工具便利不改变这项对应关系。已有模型工程、Blender和MoneyPrinterTurbo仓库不属于待安装的外部Skill；复用已确认环境，只为实际缺少的附加能力读取下表对应入口。

来源核查基准：2026-10-10。固定提交、源文件摘要与采用范围见 [外部来源索引](../indexes/external-skills.json)。安装状态取当前宿主的实际目录；“Skill已安装”与“依赖已齐、功能已经实际运行”分开判断。

## 按成片风格锁定主制作工具

先从用户要求、已确认设计与当前项目记录确定成片风格，再选主制作工具；不再按“工程类/其他题材”分流。这是本系列的工具约束，不是“优先评估”的建议：

| 成片风格 | 必须采用的主制作工具 | 具体职责与边界 |
| --- | --- | --- |
| 写实风格（实拍观感，含AI写实与有权用户自拍） | **MoneyPrinterTurbo** | 使用已有仓库完成实际素材编排或已核合成入口，结合已确认旁白、字幕与画幅导出。需要生成镜头时，本地视频模型提供素材；模型本身、FFmpeg拼接或Blender渲染不能替代MoneyPrinterTurbo制作环节。详见[写实制作流程](ai-generated-video.md)。 |
| 3D动画风格（可控三维场景与动画，含拟真材质的3D） | **Blender** | 在Blender完成主体建模/资产复用、材质灯光、相机、动画与实际渲染；配音、字幕、混音和编码可用已有辅助工具。不能用AI生成的“3D观感”视频或MoneyPrinterTurbo混剪替代Blender制作。详见[3D制作流程](engineering-blender.md)。 |

未指定风格且现有上下文没有选择时，沿系列写实默认值使用MoneyPrinterTurbo，不凭工程题材自动选Blender。上下文已有明确风格时直接执行，不重复问工具。用户后续明确改变本期风格或工具时，以其最新要求为准并记录具体范围；执行者不能借缺工具、生成困难、旧偏好或内部小样比较自行换路。必需工具不可用时说明具体缺口，继续不依赖它的研究、脚本与设计。

仅在已明确的混合风格范围内分段采用两条路线，写实段与3D动画段分别登记对应工程和镜号；字幕、箭头等辅助层不构成另一种成片风格，也不触发第二套主制作工程。封面与独立3D资产任务按各自委托执行，不因视频分流强迫封面通过MoneyPrinterTurbo。

在现有简报、逐镜设计和`execution`记录风格、主制作工具、真实工程版本与输入/输出证据：写实片保留MoneyPrinterTurbo的实际调用及合成产物，3D动画保留Blender源工程/构建代码与渲染记录。素材生成日志、配置里的工具名和纯文案调用均不能代替主制作的实际运行；结构检查通过也不认证工具实际执行或画面合格。沿G1核路线、G2/G3核实际样段、G5核最终产物，不新增平行审批。

## 按需选择与应用证据

在单集 `tool_applications` 中只记录实际选用项：`need`、`selection_reason`、`source_id`、`usage_mode`（`method` 或 `runtime`）、`read_reference`（固定 `version` 与实际阅读的 `files`）、`shot_ids`、`status`。`planned` 只表示待实施；声称 `applied` 时附 `artifact_evidence`（文件及SHA-256），由既有QA说明具体改善、未改善或新缺陷。方法参考须实际读适用正文并落实到镜头，不能以来源索引代读；只应用方法不要求运行整套框架。`runtime` 的已应用项另附 `installation_evidence` 和 `execution_evidence`，沿下节安装及最小运行验证要求执行。已有同版本同环境证据可引用，不重装。

`tool_applications` 默认空；未选的参考不填项，规划项不冒充完成。新记录绑定相关阶段上下文和镜头产物，旧批准作品不因字段新增而自动失效。

## 逐镜选择与同目标小样

先按上述风格分流锁定主制作工具；写实片执行[写实制作契约](realistic-production.md)，3D动画执行[Blender制作要求](engineering-blender.md)。下列2D工具只用于辅助层或明确委托的2D范围，不能替代两条路线的主体制作；绘图/代码动画也不能登记为视频模型调用。

- 写实氛围、环境建立与开场现象：通过MoneyPrinterTurbo制作；准备素材时复用当前已确认且有权可用的本地视频生成能力，也评估已核实用户自拍及用途授权的连续原片。第三方公开视频、CC/Commons及论文影像只能研究参考，不能因可下载或获许可变成填充镜。生成片只能作表现或示意，不能承担真实观测证据；科学论证仍须可核来源，引用论文不等于引入其视频画面；交付来源按 [原创视觉来源契约](science-and-rights.md#原创视觉来源契约)。
- 3D动画中依赖准确结构、接触次序、方向、拓扑或机构状态的过程：必须由Blender以同源几何与状态驱动整体、局部和过桥，无需先试视频模型。写实路线不能借这些要求静默换成Blender；两类输出都须核科学来源与实际连续状态。
- 已明确采用混合风格的镜头先分清每个产物的作用及对应主制作工具：例如生成环境与可控机制层分别登记来源，合成后检查对象身份、尺度、光影与前后状态；原有逐镜模态/资产台账保留，不能把合成结果误标实拍。
- 旁白、同步字幕、可核证据标注与必要图内字在后期以可编辑层合成，不依赖模型生成准确文字；它们不能补救错误主体动作或虚构证据。

主制作工具按风格确定后，若同一路线内有两种可用的素材、参数或表现方案，可用**相同解释目标**的局部小样比较，再决定投入；这不是MoneyPrinterTurbo与Blender之间的自由选型：固定必要主体、起态/终态、关键发现和相近观看条件；允许适合工具的实现不同，不要求像素一致。只运行当前授权和阶段允许的小样，不为比较启动整片、付费、上传或新安装权限。已有同目标、同条件的有效小样证据可复用，不强制每镜重做竞赛。

沿现有 `tool_applications` 与逐镜候选记录比较：实际输入/工具版本、产物哈希、正常速审看发现、科学/身份连续性、画面完成度，以及实测执行/等待时间、人工修复与失败重试。未测项保留未知；预计时长与成本不写成实测。比较结论说明采用哪条路径、已见差距及尚未验证的条件，不以生成完成或编码成功替代视觉、听感验收。不能声称未测试的模型更快、更好或已经成功，也不能将一次小样结果泛化为所有题材。

这些是既有选型与代表样证据，不新增审批层级。若仅有一条允许且可用路径，记录理由和未比较项，按已有关卡验证它；明确锁定的路径不被内部比较擅自替换。工具/素材组合改变时仅重核受影响依赖；正在运行的任务不热切换；下次续做从[唯一全局Skill](global-skill-installation.md)核最新要求和差异，明确迁移并重核受影响依赖。旧锁用于追溯，项目副本及维护源码不能继续作为生产入口。

## 调用前准备与安装

只处理本次实际需要的能力。先检查当前宿主实际目录、可读入口、已有工程和依赖；会话列表没显示不等于没安装。复用已有可用安装与同版同环境验证，不覆盖用户定制，不因引入方法资料安装整套框架。

选定runtime工具缺失时，先核本次请求及已有授权是否覆盖该安装、宿主写权限、来源和必要依赖；已覆盖就继续，不重复确认。Skill本身不提供永久安装授权。使用实际可用安装器固定来源与版本，缺失的必要兄弟依赖按实际调用链补；只读method参考不触发安装。宿主提供专用工具时遵循其约束，不绕过工具或沙箱限制。

安装后读取入口和适用正文，核文件/版本并做与本次能力匹配的最小验证。历史来源索引只说明所读提交，当前实际安装状态另核；不要为了匹配过时索引降级已确认可用环境。云传输、账户、费用、模型下载仍按各自实际授权，不由本段扩张。指定素材库已有用户持续授权时，按[归档授权正文](engineering-blender.md#素材库归档的持续授权)直接执行同范围复制与索引/回执维护，不把每次NAS归档重新当作未授权外传。

同类失败无新修复依据时停止该依赖步骤，记录原因并继续独立工作。用户指定及本页按风格要求的主制作工具不可静默替换；只有未锁定的辅助能力可选现有等效工具。运行记录与实际产物绑定，不把安装成功写成制作或审美通过。

## 交给子工具的任务

交接现有主问题、镜头/语义段时码、这一段承接的前态与结束态、整期正式旁白及已确认声音、画风参考与所用资产、画幅/fps、允许的屏上文字和输出目录。子工具产物回到当前单集工程，接回同一完整旁白。镜头切换不是语音生成边界。

整期讲解、观众文字和声音仍分别依 [制作检查点](production-checkpoints.md)、[视觉正文](visual-system.md#可见文字用途与制作辩解)、[声音正文](voice-reference.md#连续讲述与合成单元) 审查；工具的lint、帧差、ASR或编码成功不替代这些判断。子工具已经取得的真实检测结果复用到现有阶段记录，不另建一套批准流程。

当前适用写实参考约束主画面；历史自然插画只约束获准2D及独立封面范围。按题材设计构图与对象动作；上游的几何示范、固定色板、秒数和镜头特效不自动成为本片画风或科学规律。镜头推拉不能替代主体状态变化，制作说明不进入观众画面/口播，必要标识按实际义务选择位置。

## huashu-art-motion 执行

采用其场景引擎、参数化片段、动作库、资产合成及本地QA。动画语法按本镜理解任务选择：对象机制、几何推导、证据标注、数据关系分别选适合的实现；新建科普片仍采用已确认的统一画风。需要精细人物或复杂自然形体时用认可资产/生成帧，代码负责可编辑动作和合成，不用默认代码小人替代正式素材。

先核对参数化片段实际表达的关系。例如 `y1` 默认实现中心物与卫星节点，不能仅凭“科普”标签套用于杯外壁凝露；此类机制用场景代码与分层资产表达杯壁、水汽和水滴的连续状态。

读取其 `references/09-视频动画语法.md` 与选中的语法卡，或读取所需风格方法；把 `scripts/engine/` 复制到单集的新工程目录，编辑项目副本。固定实际使用的上游提交及项目改动，不向全局安装目录写入单集媒体。

以下为参数化片段入口，路径按当前宿主和单集替换；`spec` 必须使用当前镜头内容与时长：

```sh
uv run --isolated --python python3 --with playwright --with pillow --with numpy python <单集工程>/render.py --spec <镜头.json> --out <新画面轨.mp4>
uv run --isolated --python python3 --with playwright --with pillow --with numpy python <huashu安装目录>/scripts/qa.py --spec <镜头.json> --out <新QA目录>
```

上述隔离命令只是上游可选示例，优先复用已验证环境；确需安装Chromium或新建隔离环境时按当前授权和宿主权限处理。先在允许的环境运行，只有实际需要额外权限时申请，不预设所有首次渲染都要提权；不连接用户浏览器或使用绕过宿主限制的参数。

导出后用ffprobe核编码、尺寸、帧率、帧数及实际时长，并看真实抽帧；上游render打印完成不能独自证明编码成功。上游QA、film_gate/deliver的检查结果属于技术辅助，短样片通过不等于整片通过。声音沿用已确认的Qwen/Serena入口和整条旁白，不因上游提供系统声音或火山选项就换声。

上游代码/文档为MIT；字体保留各自OFL，笔顺衍生数据沿用Arphic许可，作者人物与相关帧仅供示范。生产使用自己的合法素材，完整口播范例需要另备音频与部分角色资产。

## 其他执行说明

- **ffmpeg-skill**：先读当前工具清单，按实际任务调用 `scripts/probe.py`、处理脚本及 `scripts/check.py`；输出新文件。切片/混音不改变既定旁白内容与声音。字幕烧录、文字、HDR等依具体滤镜预检结果选择；软字幕、画面渲染器字幕与烧录字幕是不同产物。
- **本地中文ASR**：优先读取已安装 `ffmpeg-skill` 的字幕文档，按 `caption.py --transcribe --language zh --engine <已准备引擎> --model <已有模型>` 识别最终剪辑。使用中文可用的本地Whisper引擎，不把默认英语Parakeet当成中文方案。已有定时字幕可直接复用；缺模型时明确缺项。音频本地处理，但首次运行可能下载模型权重；完全离线须先核实权重在本机。当前FFmpeg缺少 `subtitles`/`drawtext` 时可先交付SRT，不能宣称烧录成功。
- **HyperFrames**：产品宣传需要10个核心目录及 `product-launch-video`，不能只装router却假定兄弟引用可读。Node项目中运行其lint/check/render；设置 `HYPERFRAMES_NO_TELEMETRY=1`。上游要求的反馈提交、素材外传和云生成按实际任务授权处理，安装与本地渲染不自动授权对外发送。使用现有音轨与当前图片工具，不按镜头重新选TTS。浏览器采集遵循当前可用控制工具，独立渲染遵循宿主权限。
- **Remotion**：`remotion-best-practices` 已包含各方向参考，先读任务对应文件。复用已有项目；新项目按上游依赖要求建立，Studio使用 `--no-open`，需要显示时通过允许的浏览器工具打开。运行许可与Skill文本来源分开核实，不把Skill安装当作商用运行许可。
- **browser-video-recording**：截图/交互使用当前会话允许的浏览器工具，不能照搬不可用的工具名。配置明确的 `cursor_asset`、`cursor_hotspot`，再运行 `scripts/render_browser_demo.py --config <配置> --output <新文件.mp4>`；不要进入会全屏遮罩并移动系统鼠标的默认光标抓取分支。缺Pillow时用隔离环境。无声输出接入本片整条旁白；成片画幅由任务决定。
- **Blender 3D动画**：3D动画风格必须按[3D制作与素材复用](engineering-blender.md)制作主镜、建立同源资产与连续过桥，并将已用3D素材归档到指定共享库；不要求重建已有可用资产，也不把视图渲染当作定量模拟。
- **MoneyPrinterTurbo 写实视频**：写实风格必须按[写实制作流程](ai-generated-video.md)使用已有MoneyPrinterTurbo；需要AI镜头时由本地视频模型准备素材，再实际交其编排/合成；缺能力时修该本地链路并记录缺口。seedance2-skill 等仅提示词方法参考，不是本地模型的替代渲染器，也不因名字出现在表中就转用云服务。
- **需要模型或服务配置的候选**：保留确切缺项，完成对应准备和小样验证后才调用。未核实来源的名称不生成猜测命令；云转录/翻译不伪装本地处理，也不静默切换服务。当前任务只需本地剪接时按场景选择编辑器，再按调用前安装要求补齐并验证。
