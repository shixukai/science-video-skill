## 本集

- 可识别的自然现象/日常问题与观众收获（优先天气、动植物、海洋、地球、声音、光学）：
- 本集只回答的核心问题；观众已经见过什么、疑问是什么；理解机制前须认识的对象/部件/状态：
- 片内主题引入与过渡：现象钩子后接主题一句，或主题先行；本期讲什么/接着能明白什么、对应口播与简短叠加标题、如何自然接入首个解释镜头。不能只在发布简介写主题，不设固定秒数或机械问候
- 片内第一屏：明确对象/现象＋一个具体问题/主题；对应主视觉、手机大小可读的标题、同主题口播及接入解释的方式。封面/简介不代替片内画面，不固定字体倾斜或时长，不夸大标题、不加大黑标题板
- 一句话结论及适用条件：
- 受众默认没有专业背景的普通大众；目标端、当前要求交付的阶段：
- 真实素材锚点：主题相关对象/现象、合法来源、出现位置及解释作用；开头优先但不固定；如何连贯进入标注/放大/剖面/2D机制，所需素材或授权缺项
- 解释形式：纯2D插画与动画；不用3D模型渲染或伪3D模型，真实素材与2D对象/机制连续对应
- 专业参照：来源/版本、所依据的轮廓比例/关键结构/线条/色彩/版式、适用边界；事实依据与风格参考分开，实际导出并排差距与有依据的简化
- 系列锚点（沿用版本或暂定）：名称/标记、字体层级、配色、字幕、声音语气
- 预计长度与理由（依内容调整）：
- 中文解说：当前 Qwen 参考配置、实际模型/音色/指令及改动、制作状态、解说素材 ID；短样引用/认可范围与当前整片验收分别记录：
- 外部配音：本次文本、具体目的地、用途和授权范围；仅文字授权不含视频/参考声音，配额失败不绕过或自动付费：

## 口播与分镜

选题/脚本先做普通读者复述：本集解释什么、为什么发生；写出简短预期答案、需要解释的术语和因果缺口。标明编辑自审或实际读者反馈，不把自审写成用户已看懂。避免抽象数学/统计/随机概率教学题材；简单必要数字可帮助理解现象，不安排公式推导或统计图识读课。

按需增加镜头。每条记录镜号 / 之前状态→改变因素→结果 / 口播与对应变化 / 真实素材锚点及选定解释媒介 / 主张 ID / 素材 ID / 标签与字幕 / 同一对象如何连续识别。时段根据实际配音及理解停顿确定，不机械等分；缺少所需素材、授权或能力时如实记阻塞，不能用无关或伪真实画面填空。

逐段声画映射：实际口播句 / 画面对象 / 动作或状态变化（之前→因素→结果）/ 就近图内短标签或关键词 / 对应真实语音时点 / 实际导出检查时间点与结果。标签不是复制字幕；只换底部字幕而主图无对应变化的段落标返工。开头另写明确主题陈述，不以现象钩子或疑问自动代替。

逐镜执行记录：按 [shotbook 字段约定](../references/shotbook.md) 填成品音轨校验、镜头起止/对象/动作/景别/支持陈述、逐拍触发词与唯一注意力主角、候选实看和所选来源区间、关键帧文件与具体审看结论；有声代表镜先验，修改后重新对齐和签收。

代表性小样：选择哪个难点与理由 / 参照与整体、关键细节、机制实际帧并排 / 约10–20秒或覆盖所需变化的短样文件 / 连续片段检查时间点 / 具体差距、退回修复与复查；先审小样再整片或批量，时长与“精美”措辞都不代替通过。无对应声音/画面检查能力就分别记未验。

列出实际要烧录的文字及用途：标题、同步字幕、必要术语/图例/单位/条件、真实性标签和强制署名。完整来源、制作声明与内部记录放配套/简介；本简报及 episode.json 不得整批搬进视频，不常驻制作、版本、测试验收、模型工具或流水线字样。

## 两种封面

- 3:4：主体、标题断行、标记、视觉重心、安全区
- 4:3：重新安排以上元素，不机械裁切

## 实际验收记录

事实、理解、美术/声音、技术、平台分别记录；用实际检查对象/版本、方法、时间点、结果和修复写短句，未做的保留“未做”。不由技术通过或自填 QA 推断其他项。

- 科学：关键句与依据；不确定性、数字、术语
- 大众理解：编辑审前提/术语/因果覆盖/声画同步；有真实试看则记其复述、简单条件变化问题的实际回答与首次困惑点。没有真实反馈写“编辑自审；理解效果待验证”，模型扮新手不算实测。用户表示看不懂则内容验收失败，技术/ASR/完播不能覆盖
- 声画与图内字：静音定位对象、动作和关系，再带声连续逐段核实际口播、机制事件与就近标签是否呼应；字幕同步单列，时间码或自填映射不代签。记录脱节的时间点与返工结果
- 开场衔接：实际听当前导出，记读出的本期题目/核心问题、紧随的简短总答或解释路线及各自时间段；只有标题或脚本文字不算通过。实际听看片头，能否知道本期现象/问题及下一步要解释什么；无突兀实验/术语、主题未只留在发布简介，标题保持满幅叠加
- 第一屏验收：实际导出的小屏画面能否一眼认出对象与具体主题，主体/标题直接对应、连续播放可读；主题口播与标题一致并自然进入解释。不能把封面清楚记作片内已通过
- 权利：待清项、署名、模拟/AI标记
- 实际帧：首尾、逐镜、最密字幕、转场、动效极值；记录发现问题的时间点
- 字幕背景：真实字体/字号/断行字形外缘（含描边）+必要padding随句适配，无固定大横框；中轴/阅读基线稳定，换句不拖动字层。实际短一行/长一行/两行/换句边界及连续片段检查，亮暗背景与最终平台另验；不缩字号或占安全区，样片参数不当通用常量
- 下方解说字幕：在实际完整画面下方，与主体/图内标签分层；最长两行和换句边界对照最终完整平台UI，不把中部字幕称为底部或用通用Y坐标/百分比代替验收
- 9:16视觉满幅：实际导出首中尾/运动极值与连续片段，无独立大黑/深色标题板；标题字幕叠加且遮罩局部，不整体缩移。无拉伸、科学主体/脚点裁损或填空造影；区分素材原有暗区与人工黑边，2D场景连贯且无无意义装饰。尺寸/外框中心不能代签，内容理解与平台字幕另验
- 2D造型/线条/色彩层次/排版/运动/科学对应质量：按[质量验收](../references/quality-acceptance.md)记录检验项 / 参照定位 / 当前导出时间点与全景或细节证据 / 具体差距 / 退回条件 / 修复后复查；无占位形体、图层穿插错误、无依据漂浮、接缝/闪烁或无依据遮挡，不凭技术名称/自动分数签通过
- 方位与结构：逐镜记录对象自身/画面左右、正侧背视角、关键结构事实参照、镜像/翻转及跨镜转换复核；保存全景/细节与连续片段，缺依据或方向错误退回
- 箭头/引线：逐条清点，来源/版本/许可固定入素材台账；检查尖端、杆头连接、缩放裁切遮挡、方向含义、起终点与运动极值，无向引线另记；实际像素证据不能由代码存在代替
- 画面文字：逐镜核对全部标题/字幕/角标/页脚/图例/转场，无内部制作或验收信息；必要模拟/AI标签、平台要求与许可强制署名保留，完整来源与制作声明已进配套/简介
- 居中与边界：实际导出画布宽高/几何中心、主体完整轮廓/光学重心/留白；主体与字幕/UI分层，非居中叙事理由；代表小样修前后、首中末/运动极值实帧。不能整幅缩移制造偏位空白，用户提出偏位后撤销对应旧视觉通过
- 手机与平台：实际账号、最终标题/完整简介/tag、已加载 UI、设备/预览方式、首中末及动态字幕截图时间点；核对用户名/互动栏/文案遮挡，改视频或文案后复查。区分实机、平台手机样式预览、本地播放器与代理缩图，未检查的如实标明
- 解说：逐段及完整导出实际试听、自然口语、与稿件一致且无漏词/重复/跑词、术语/数字/单位发音、语义停顿、音色和衔接一致、字幕逐句同步；异常时长先核查，记实际试听对象与范围，短样认可不算整片通过，未实听填“未验”
- 声音：手机/耳机实听，配乐不遮人声、噪音、突变、合成声明；不克隆真人或擅自付费
- 工具检查：命令、退出状态、未检项目；解码与视觉结论分开，代码/规则回归不证明成片质量
- 冻结与复查：整批被否定时记录受影响范围、撤销的当前交付/发布结论、共同根因、代表修复小样与逐项复查；不只修被点名局部。保留仍适配的已认可音频，完整实听与真实新观众反馈分别留证，未做记未验；不自动改已发布内容
